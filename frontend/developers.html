Developers

Revoco is a FastAPI backend with a server-rendered static frontend. All state lives in PostgreSQL (Neon); all merchant traffic authenticates via an httpOnly JWT session cookie.

Authentication

Google OAuth issues a session; the session is an HS256 JWT (merchant id + email, 24h expiry) stored in the httpOnly recoverai_session cookie. Protected routes take the get_current_merchant dependency and return 401 without a valid session.

Decision schema

The recovery agent returns exactly this structure (validated against a JSON schema before anything else happens): 

{
  "diagnosis": "string — root cause of the failure/abandonment",
  "recovery_probability": 0.0-1.0,
  "recommended_action": "recover_now | send_payment_link | wait_and_retry
                       | escalate_to_merchant | stop",
  "reason": "string — reasoning citing enriched context",
  "confidence": 0.0-1.0
}

Summary payload shape

GET /dashboard/summary returns three blocks — detection (simulated benchmark counts), real_execution (scenarios, decisions, per-transaction audit chains, webhook-confirmed recovery), and agent_evaluation (agent vs deterministic benchmark + verdict). Field-level details in the repository README and backend/GROUND_TRUTH_POLICY.md.
